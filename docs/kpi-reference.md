# KPI Reference

Generated by `scripts/kpi_reference.py` from the semantic model (`VoltrixSupplyChain.SemanticModel`, table `_KPI Measures`, **104 measures**) and the published CSVs in `data/generated/`. Do not edit by hand: re-run the script after any model or data change.
Every formula below is the exact DAX in the model; every value is the default state (no slicers), as-of **2025-12-31**, computed in pandas with the same filter semantics.

- **Dataset**: Voltrix Electric SE (fictional), 2024-01-01 .. 2025-12-31, EUR, seed `20250920`
- **Validation**: the pipeline recomputes the headline KPIs in Python (`scripts/sc_kpi.py`) and checks them against the plausibility bands in V8 on every run (`data/validation/kpi_values.json`); `python scripts/kpi_reference.py --check` fails if this file is stale

## The as-of rule

A line enters a service denominator only once it is **due** (`RequestedDeliveryDate` / `ExpectedDeliveryDate` <= as-of). A due line not fully delivered by the as-of date is a failure; an undelivered line that is not yet due is open, not failed. Only deliveries dated on or before the as-of date count.

## Date filtering

Sales and purchase lines are filtered by **order date**, receipts by receipt date, shipments by ship date and the snapshot by snapshot date (the requested / expected-date relationships are inactive). Point-in-time measures (inventory value, ending units, below-ROP count) return the value on the **last day** of the selected period.
